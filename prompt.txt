CRITICAL CURRENT BUG / GAP
==================================================

packages/privacy-core/src/browser-action-engine.js currently contains:

    this.domDriver = customConfig.domDriver || null;

and execution roughly does:

    if (this.domDriver && typeof this.domDriver.execute === "function") {
        this.domDriver.execute(actionType, targetResolution.targetId, parameters);
    }

If domDriver is null, execution is silently skipped but executeAction() can still return:

    ok: true
    status: ACTION_RESULTS.COMPLETED

This is a FALSE SUCCESS bug.

        performScroll

    src/policy-runtime.js
